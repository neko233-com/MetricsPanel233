# Support

- For confirmed defects, open a GitHub issue with the version, operating system, relevant component and a minimal reproduction.
- For feature ideas, explain the problem, expected behavior and the compatibility or deployment context.
- For usage questions, include sanitized configuration and command output. Remove passwords, tokens, private URLs, customer data and encryption keys.
- For security reports, follow [SECURITY.md](SECURITY.md); do not use a public issue.

The project is pre-1.0 and does not promise a support SLA. Check the README and compatibility documents for current capabilities and known gaps before opening a request.
