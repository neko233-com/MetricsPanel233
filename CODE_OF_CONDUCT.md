# Code of Conduct

MetricsPanel233 follows the [Contributor Covenant Code of Conduct, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

We are committed to a welcoming, respectful and harassment-free experience for everyone who participates in project discussions, issues, pull requests and other community spaces.

Report conduct concerns privately to a repository maintainer through a contact channel listed on their GitHub profile. Please do not post personal information or sensitive reports in public issues.
