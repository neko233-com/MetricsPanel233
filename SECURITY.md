# Security Policy

## Reporting a vulnerability

Please do not report suspected vulnerabilities in public issues or discussions. Use GitHub's private vulnerability reporting for this repository when it is available. If private reporting is unavailable, contact a repository maintainer through a private channel listed on their GitHub profile.

Include the affected version or commit, the impact, and the smallest reproduction you can provide. Do not include real credentials, production data or tokens; use synthetic examples.

## Supported versions

MetricsPanel233 is pre-1.0. No long-term support or backport schedule is promised. Security fixes are prepared against the current development branch; users should review release notes and update to a maintained release when one is published.

The project does not publish a guaranteed response or remediation timeline. Maintainers will coordinate disclosure and a fix with the reporter where practical.
